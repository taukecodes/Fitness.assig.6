# 🏋️ FitLog — Workout Tracking Web App

**FitLog** is a clean, responsive workout and fitness tracking web application designed after a Penpot layout to help users organize routines and monitor their training progress effortlessly.

🔗 **Live Demo:** [https://fitness-site-one-amber.vercel.app](https://fitness-site-one-amber.vercel.app)

## ✨ Major Features
- **Workout Routine Management:** Log, organize, and track workout sessions cleanly.
- **Design-Accurate UI:** Built with visual fidelity to a Penpot design system using clean spacing and modern cards.
- **Responsive Layout:** Adapts smoothly across desktop, tablet, and mobile viewports.
- **Fast & Interactive Experience:** Smooth client-side state updates and instant visual feedback.

- **Design Reference:** Penpot
- **Deployment:** Vercel
